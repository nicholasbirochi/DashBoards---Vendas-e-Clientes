# Dashboards de vendas e clientes

Dois estudos de visualização de dados com Power BI. O repositório mantém os relatórios junto das planilhas e dos documentos usados na organização dos indicadores.

## Projetos

- `FinalProject/`: relatório `N1.pbix`, planilha `BD-Exportador.xlsx` e documentação dos KPIs em Word e PDF.
- `Projeto DashBoard/`: relatório `DashBoard.pbix` e a planilha `DadosN2.xlsx`.

## Como consultar

Abra os arquivos `.pbix` no Power BI Desktop. Se o relatório apontar para um caminho de dados da máquina original, ajuste a fonte para a planilha correspondente deste repositório antes de atualizar as consultas.

Os documentos em `FinalProject/` ajudam a entender quais indicadores foram escolhidos. Não há aplicação web nem atualização automática de dados neste repositório.
